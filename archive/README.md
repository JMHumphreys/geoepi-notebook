# Archived Lab Book material

This directory preserves the first, lifecycle-oriented GeoEpi Lab Book
material for future reference. It is not part of the active Quarto site and is
not a second set of current guidance.

The active site now focuses on how GeoEpi organizes projects, subprojects,
data, computing, collaboration, and products. The archived pages may be
revisited when the Lab later develops detailed scientific or domain guidance.
